# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий следует [семантическому версионированию](https://semver.org/lang/ru/).

## [1.0.0] - 2026-08-18

Первый релиз.

### Добавлено

- История текстового буфера обмена через `WM_CLIPBOARDUPDATE`.
- Локальное хранилище SQLite в `%APPDATA%\Klip\klip.db`.
- Копирование записи обратно по клику.
- Закрепление избранного: закреплённые записи не вытесняются из истории.
- Поиск по заголовку и тексту.
- Типы записей: фрагмент, заметка, код, ссылка. Ссылка и код определяются сами.
- Цветовые метки: без метки, небо, шалфей, глина, песок.
- Папки-коллекции.
- Глобальная клавиша Ctrl+Shift+V - показать и скрыть окно, в том числе из трея.
- Значок в области уведомлений, закрытие сворачивает в трей.
- Запуск вместе с Windows через HKCU Run.
- Редактор новой заметки: заголовок, текст, тип, метка, папка.
- Удаление записей и папок.
- Окно без стандартного заголовка, тёмная тема, Mica/Acrylic на Windows 11
  и сплошной фон `#0B0D11` на Windows 10.
- Сборка одним файлом win-x64, установщик Inno Setup, MSI на WiX и портативный zip.

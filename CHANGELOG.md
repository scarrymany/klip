# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий следует [семантическому версионированию](https://semver.org/lang/ru/).

## [1.2.1] - 2026-08-19

### Исправлено

- Миниатюры снимков показывают изображение целиком без растягивания и обрезки краёв.

## [1.2.0] - 2026-08-19

### Добавлено

- Автозахват изображений из системного буфера, включая снимки `Win + Shift + S`.
- Раздел «Изображения» с миниатюрами, полноразмерным просмотром и сохранением PNG.
- Клик по изображению возвращает его в буфер, закрепление защищает от автоматической очистки.

### Изменено

- PNG хранятся локально в `%APPDATA%\Klip\images`, а SQLite содержит только метаданные.
- Незакреплённая история изображений ограничена 100 файлами; размер одного PNG ограничен 25 МБ.

## [1.1.2] - 2026-08-19

### Добавлено

- Кнопка Telegram в заголовке окна открывает профиль `@yeet17`.

## [1.1.1] - 2026-08-19

### Добавлено

- Кнопка GitHub в заголовке окна открывает репозиторий в браузере по умолчанию.

### Исправлено

- Настройки оформления больше не обещают Mica/Acrylic: окно использует layered WPF на Windows 10 и 11.

## [1.1.0] - 2026-08-18

### Добавлено

- Миграции SQLite через `PRAGMA user_version`.
- Повтор уже сохранённого текста поднимает старую карточку, а не плодит копию.
- Юнит-тесты и шаг `dotnet test` в CI.
- Файл `Klip.installed` в EXE/MSI, чтобы апдейтер отличал установку от портативки.

### Исправлено

- Чтение буфера больше не замораживает UI через `Sleep`.
- Список не перечитывает всю базу на каждый Ctrl+C: в список идёт превью, полный текст подгружается при копировании и правке.
- Поиск идёт по всей записи в SQLite, а не только по превью.
- Слайдеры оформления пишут настройки с задержкой, а не на каждый тик.
- Окно больше не открывается за краем экрана после смены мониторов.
- Контрольная сумма обновления считается потоком, без загрузки всего файла в память.
- Текст релиза в GitHub Actions берёт версию из тега, а не захардкоженный 1.0.10.

### Изменено

- Обрезка истории трогает только автозахват из буфера. Заметки и закреплённое не вытесняются.
- README описывает реальное окно (layered, без DWM Mica) и проверку обновлений на GitHub.

## [1.0.10] - 2026-08-18

### Исправлено

- Дёрганая прокрутка в настройках: вместо сбрасывающейся анимации — инерция по кадрам, фон с фото кэшируется.

## [1.0.9] - 2026-08-18

### Добавлено

- Плавная прокрутка в настройках, списке записей и боковой панели.
- Переход между разделами буфера с лёгким сдвигом и проявлением.

## [1.0.8] - 2026-08-18

### Исправлено

- Белые треугольники в углах: окно стало layered (`AllowsTransparency`). Углы реально прозрачные, без `SetWindowRgn` и без белой подложки Win32.

## [1.0.7] - 2026-08-18

### Исправлено

- Окно снова реально скруглено: при фоне-фото DWM не скругляет HWND, поэтому клип идёт через регион. Подложка непрозрачная — без белого ореола.

## [1.0.6] - 2026-08-18

### Исправлено

- Белый ореол по контуру окна: `SetWindowRgn` рисовал края на белом фоне Win32. Скругление снова через DWM, подложка тёмная.

## [1.0.5] - 2026-08-18

### Добавлено

- Закруглённые углы окна (16px) на Windows 10 и 11. В развёрнутом виде — без скругления.

## [1.0.4] - 2026-08-18

### Исправлено

- Крестик в настройках срабатывал только нижней половиной: зона заголовка окна перехватывала клик.
- Полоса прокрутки настроек больше не наезжает на цифры размытия и затемнения.

### Изменено

- Панель настроек и редактор появляются с лёгким масштабом и затемнением.

## [1.0.3] - 2026-08-18

### Исправлено

- Автообновление находило `*Klip-Setup-….exe` в `SHA256SUMS.txt` (формат Git Bash на Windows) и отказывалось ставить релиз.

## [1.0.2] - 2026-08-18

### Добавлено

- Кнопка «Настройки» в боковой панели вместо кривой текстовой ссылки.
- Оформление: выключить прозрачность, цвет акцента и подложки.
- Своё фото на фон: заполнить / растянуть / вписать, размытие, затемнение.
- «Цвет из фото» подбирает тёмную подложку под снимок.

## [1.0.1] - 2026-08-18

### Добавлено

- Автообновление: Клип проверяет GitHub Releases при запуске и раз в 4 часа.
- Карточка справа сверху, если вышла новая версия, с кнопкой «Обновить».
- Установленная копия обновляется тихим Inno Setup, портативная — заменой `Klip.exe`.
- Файл обновления сверяется с `SHA256SUMS.txt` до установки.
- В боковой панели: текущая версия и ручная проверка.

## [1.0.0] - 2026-08-18

Первый релиз.

### Добавлено

- История текстового буфера обмена через `WM_CLIPBOARDUPDATE`.
- Локальное хранилище SQLite в `%APPDATA%\Klip\klip.db`.
- Копирование записи обратно по клику.
- Закрепление избранного: закреплённые записи не вытесняются из истории.
- Поиск по заголовку и тексту.
- Типы записей: фрагмент, заметка, код, ссылка. Ссылка и код определяются сами.
- Цветовые метки: без метки, небо, шалфей, глина, песок.
- Папки-коллекции.
- Глобальная клавиша Ctrl+Shift+V - показать и скрыть окно, в том числе из трея.
- Значок в области уведомлений, закрытие сворачивает в трей.
- Запуск вместе с Windows через HKCU Run.
- Редактор новой заметки: заголовок, текст, тип, метка, папка.
- Удаление записей и папок.
- Окно без стандартного заголовка, тёмная layered-подложка и прозрачные скруглённые углы.
- Сборка одним файлом win-x64, установщик Inno Setup, MSI на WiX и портативный zip.

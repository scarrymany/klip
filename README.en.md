# Klip

Personal clipboard history and notes for Windows 10/11. Mica/Acrylic on Windows 11, local SQLite, no network.

See the [Russian README](README.md) for full docs, badges and installers.

| Asset | Role |
| --- | --- |
| `Klip-Setup-1.0.10.exe` | Inno Setup installer |
| `Klip-1.0.10-win-x64.msi` | Per-machine MSI |
| `Klip-Portable-win-x64.zip` | No-install zip |

Hotkey: `Ctrl + Shift + V`. Auto-update checks GitHub Releases and shows a card in the top-right.
